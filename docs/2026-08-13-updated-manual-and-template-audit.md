# GOAI 新版指导手册与最新初赛模板审计

> 日期：2026-08-13（Asia/Shanghai）  
> 新版来源：`../AI fo research指导手册2.pdf`，38 页  
> 旧版来源：`../AI for research指导手册.pdf`，36 页  
> 模板来源：`../初赛作品提交模板（最新）.zip`  
> 性质：团队内部事实与合规审计，不是可直接提交的初赛作答。

## 1. 结论先行

新版不是文字微调，而是改变了方向二的正式实验边界。项目必须立即从“基于 MISATO-100 复现和推测权重优化”转为：

1. 以全量 MISATO 为正式数据基座；剔除 NeuralMD `peptides.txt` 多肽后，官方口径为训练 `13,066`、验证 `1,357`、测试 `1,357`。
2. 固定 T1=`10→10`、T2=`80→20`、T3=`20→80`，新增可选 T4 长程加分项。
3. 保留 Geo/Phys/Dyn/Stab 四维评价，但新版删除旧版公布的 `40/25/25/10` 与 `50/30/20` 权重；精确定义、权重和合成方式随复赛通知发布。此前权重只能标为“旧版规划口径/内部代理”，不能称当前官方评分。
4. 统一 semi-flexible：蛋白不动，只预测配体原子坐标序列。
5. 新增外部资源硬约束：预训练模型、外部 MD 数据不得包含测试复合物或其近同源体系；MISATO/PDBBind 公开重叠被明确点名。
6. 初赛不做方向二主榜轨迹提交，也不涉及官方 Geo/Phys/Dyn/Stab evaluator；初赛任务是按最新算法赛模板呈现方案、科学理解、阶段验证、复现与合规。

## 2. 旧版到新版的关键变化

| 事项 | 旧版 | 新版 | 项目动作 |
|---|---|---|---|
| 数据划分 | 表述为 13,066 train；1,357 validation/test，存在歧义 | 明确 train/validation/test 分别为 13,066/1,357/1,357，且剔除 `peptides.txt` | P0 获取全量 HDF5 和 split，逐 ID 核对多肽排除 |
| 数据来源 | MISATO | MISATO 公开数据 + 组委会独立评测数据 | 不把公开 internal test 当隐藏测试；保留外部分布泛化风险 |
| T1 | 短程，未给精确 k | 前 10 帧预测后 10 帧 | 修改 scenario evaluator |
| T2 | 前 80% 预测后 20% | 前 80 帧预测后 20 帧 | 现有 100 帧实现与之对齐 |
| T3 | 前 20% 预测后 80% | 前 20 帧预测后 80 帧 | 现有 100 帧实现与之对齐 |
| T4 | 无 | 可选长程加分项 | 初赛仅列后续路线，不挤占 P0/P1 |
| 四维权重 | Geo/Phys/Dyn/Stab=`40/25/25/10` | 暂不公布 | 停止声称官方权重；只报告原始指标与相对基线变化 |
| 场景权重 | T1/T2/T3=`50/30/20` | 暂不公布 | 旧加权 proxy 仅保留为历史筛选，不作当前优化目标 |
| 正式 evaluator | 旧文档容易使人误以为可自行还原 | 明确复赛通知发布，初赛不涉及 | 不猜官方总分；初赛用可解释代理证据 |
| 外部预训练 | 可用且披露 | 可用、须披露，且不得包含测试/近同源体系 | 任何 checkpoint 先做来源和重叠审计 |

| 决赛 | 下游应用题 | 方法与结果、专家问答 | 当前不按旧“指定下游应用题”规划 |

## 3. 最新算法赛初赛模板字段

模板要求六部分，团队最终必须独立撰写。项目只提供以下证据映射：

| 模板字段 | 可使用的内部证据 | 当前缺口 |
|---|---|---|
| 1 项目概述 | 方向二任务、semi-flexible、T1/T2/T3；本仓库 README | 项目名称和最终一句话主张由团队确定 |
| 2 科学问题理解 | NeuralMD 复现、长时漂移、Static 防塌缩、Geo/Phys/Dyn/Stab 代理审计 | 需团队用自己的语言解释科学意义 |
| 3 技术方案与路线 | NeuralMD 基线、causal Transformer 多种子结果、ProAR/PVB/EPT 候选审计 | 全量数据尚未就绪；预训练泄漏尚未通过 |
| 4 阶段性验证 | NeuralMD 精确复现；E13-E17 负结果；多种子时序/RoPE 报告 | 目前均为 MISATO-100 feasibility，不代表正式全量表现 |
| 5 复现与开放 | 测试、配置、预注册、原始 JSON、Git 历史、第三方清单 | 项目 LICENSE 未由团队确定；外部权重数据清单不完整 |
| 6 团队介绍 | 魏子安、耿健尧、熊润的已知背景与分工记录 | 最终成果链接和表述由团队确认 |

## 4. AI 使用边界

最新模板明确写有“独立完成，禁止使用 AI 作答”。因此：

- 可以继续使用本项目生成和核查代码、实验配置、原始数据、图表、复现命令、论文事实、失败记录、证据索引和合规清单；
- 不生成或填充可直接上传的模板正文，不替团队完成最终观点、叙事和回答；
- 团队成员应独立阅读证据，独立撰写模板，并逐条核对事实、引用、外部资源与许可证披露；
- 若组委会后续给出更具体的 AI 使用解释，以最新正式公告为准。

## 5. P0 风险

1. 全量 MISATO `MD.hdf5` 约 132.8 GB；服务器当前只有 725 MB 的 MISATO-100。
2. 官方新版提到的“剔除 `peptides.txt` 后 split”需与实际文件逐 ID 校验，不能仅相信计数。
3. PVB 和 EPT 都使用 PDB/PDBBind 预训练；如果训练样本清单不可得，则无法证明不含比赛测试或近同源体系。
4. 最新模板要求披露许可证与关键版本；项目自身 LICENSE 尚未由团队选择。
5. 官方 evaluator 与正式权重尚未发布；内部 proxy 不能包装为官方得分。

## 6. 近期交付门槛

- 初赛前必须：完成新版证据映射、冻结小规模可行性结果、明确全量数据获取状态、列出预训练方案的泄漏限制、完成人工模板撰写与合规复核。
- 复赛准备必须：完成全量 split、去泄漏验证、正式 T1/T2/T3 pipeline、外部资源 manifest、全量或代表性多种子结果。
- T4、1.4B 级模型、复杂多模块集成只有在 P0/P1 完成后才进入队列。
