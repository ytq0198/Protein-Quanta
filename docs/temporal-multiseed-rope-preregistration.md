# 时序架构代码审计与多随机种子 / RoPE 预注册

日期：2026-08-13  
状态：在查看任何新增 seed 与 RoPE 结果前冻结

## 审计结论

原时序筛选正确使用 80 个训练复合物与 10 个 validation 复合物，未访问 internal test；所有输入均为刚体运动不变的 12 维轨迹摘要，模型参数量低于 10k。不过存在两项会放大探索性结论的设计风险：

1. 只有 seed 42，80 条相互独立的训练轨迹不足以排除初始化与 batch 顺序偶然性。
2. 每 10 epoch 在同一 validation 上选择最佳轮数，之后又用同一 validation 比较架构，存在二次选择偏差。

另发现 Static 特征对照的实现错误：结构特征应重复最后观察值，但真正静态的未来坐标位移为零；旧实现却重复最后一个非零位移摘要。该错误不改变五个学习模型彼此的数值和排序，但会改变“是否超过 Static”的 gate。旧报告保留作为探索记录，不能再作为晋升证据。

## 新实验的唯一变量与控制

- 固定 epoch 200，不根据 validation 挑 epoch；训练过程中保留曲线只用于诊断。
- seeds 固定为 0、42、123，所有架构使用相同数据、优化器和更新预算。
- 比较 MLP、RNN、LSTM、GRU、绝对正弦位置 Transformer、RoPE Transformer。
- RoPE 只旋转每个注意力头的 query/key 偶数维通道，不向 value 或输入添加绝对位置向量；其余为两层 pre-norm causal attention，隐藏维度 16、4 heads、FFN 宽度 32。
- Static 对照在原始物理空间将未来四个 step-magnitude 特征设为零，再使用训练集统计量标准化。
- internal test 禁止访问；本实验也不生成正式比赛分数。

## 晋升门槛

候选必须同时满足：三 seed 平均方向权重 RMSE 优于 MLP；至少 2/3 个配对 seed 优于 MLP；平均超过 Static 至少两个场景；T2 或 T3 相对 MLP 至少改善 5%；全部 rollout 有限。即使通过，也只允许进入带等变空间编码器的 3D pilot，不能替代当前安全基线。

## 预期解释

- RoPE 若仅改善 T2/T3 而损害 T1，支持“短程局部路径 + 长程相对位置注意力”的场景自适应假设。
- 若均值改善但 seed 一致性失败，视为小数据方差而非有效创新。
- 若所有时序核心均失败，优先转向数据表示、训练闭环与空间等变性，不继续扩大普通 Transformer。
