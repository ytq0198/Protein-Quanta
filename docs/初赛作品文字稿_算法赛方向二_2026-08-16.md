# AI for Research 赛道｜算法赛初赛方案

## 一、项目概述

### 1.1 项目名称

**Protein-Quanta：面向蛋白质-配体长时程动力学预测的可控等变学习**

### 1.2 参赛方向

算法赛方向二：虚拟细胞方向的蛋白质-配体动力学轨迹预测。

### 1.3 方案概述

我们研究的是半柔性条件下的配体轨迹预测：蛋白质保持不动，模型根据已经观测到的配体原子坐标，继续预测后续三维轨迹。比赛包含三个主要场景：T1 用前 10 帧预测后 10 帧，T2 用前 80 帧预测后 20 帧，T3 用前 20 帧预测后 80 帧。其中 T3 最能暴露长时间滚动预测中的误差积累问题。

我们的方案不是简单地换一个更大的序列模型，而是先把问题拆开。第一步复现 NeuralMD，并把数据、单位、时间步和评估场景核对清楚；第二步分别研究空间几何和时间外推，空间上使用 E(3) 等变结构，时间上使用多时间尺度闭环训练；第三步针对实验中出现的“坐标误差下降但运动幅度塌缩”问题，引入 control-anchored gated E(3) residual。它以稳定的控制模型为锚点，只学习受门控的等变修正，避免新模型一开始就破坏已有的稳定性。

目前，我们已经完成全量 MISATO 数据核验、NeuralMD 基线复现、时间和速度单位审计，以及多组时序和三维等变实验。多时间尺度闭环在时序代理任务上稳定改善长程预测；锚定式等变残差已在真实复合物上通过安全初始化、可训练性和 E(3) 等变性测试。下一步是把两部分合并，在完整三维任务上做统一的效果验证。

## 二、科学问题理解

### 2.1 科学问题与研究对象

分子动力学轨迹不是一组互相独立的三维坐标。配体每一步的运动都受到自身构象、蛋白质口袋环境和前序状态的共同影响。用模型做闭环预测时，前一步的偏差会继续传到下一步，所以短期误差不大的模型，在长时间推演后也可能明显漂移。

这个任务还有两个容易被忽略的问题。

第一，原子坐标处在三维欧氏空间。把同一个复合物整体平移或旋转，不应该改变模型对其内在运动的判断。因此，模型需要满足相应的几何对称性，而不能只把坐标当作普通数值序列。

第二，只看坐标 RMSE 可能会得到错误结论。如果模型把配体预测得几乎不动，在局部波动较小的数据上也可能取得较低误差，但这种轨迹并没有学到正确的动力学。我们在实验中确实观察到了这一现象：速度感知模型大幅降低了小规模实验的 RMSE，却同时出现运动幅度过小和高比例梯度裁剪。因此，我们把这道题理解为一个同时受长序列误差、三维几何约束和动力学合理性约束的问题，而不是单一的坐标回归。

### 2.2 科学意义

蛋白质-配体的动态行为与结合口袋中的构象变化、局部相互作用和稳定性有关。传统分子动力学能够提供这类信息，但长时间模拟的计算成本较高。一个可靠的学习型动力学模型可以作为快速近似工具，为候选构象筛选、轨迹分析和后续高精度模拟提供参考。

从方法上看，这个题目也有较明确的研究价值：小数据条件下，长序列模型、几何等变性、数值单位和闭环训练目标如何配合，目前仍没有简单答案。我们希望通过可复现的对照实验说明哪些改动真正改善了长程外推，哪些改动只是降低了表面误差。即使某个候选模型失败，这些结果也能帮助定位动力学模型中的误差来源。

## 三、技术方案与预期方法路线

### 3.1 技术方案

整个方案分为五个部分。

**1. 数据和协议审计。** 我们以最新版指导手册中的 MISATO 划分和 T1/T2/T3 定义为统一口径。全量 `MD.hdf5` 的大小为 132,841,014,019 字节，MD5 为 `9bc6446922cd80e0f2f3f69349bf88ed`，包含 16,972 个复合物。剔除 NeuralMD 的多肽列表后，训练、验证和测试数量分别为 13,066、1,357 和 1,357。我们还核对了 HDF5 中的复合物 ID 与三份原始划分的并集，结果完全一致。

**2. NeuralMD 复现基线。** 我们固定 NeuralMD 的上游版本、官方检查点和评估配置，重新实现最新版的三个预测场景。已发表的 NeuralMD 目前仍是我们的主基线。新方法只有在坐标、动力学幅度和稳定性上同时通过门槛，才会替换它。

**3. 空间和时间建模。** 空间部分使用相对位置、原子类型、距离和速度不变量进行消息传递，输出满足 E(3) 等变性的坐标或加速度修正。时间部分比较了循环网络、因果 Transformer、RoPE 和多时间尺度闭环监督。现有实验表明，单纯延长序列模型并不够，训练时实际看到的 rollout 长度需要覆盖长程场景。因此后续三维模型采用 `[5,10,20,40]` 的多时间尺度闭环损失。

**4. 锚定式门控等变残差。** 这是当前的主要创新方向。设控制模型输出为 \(a_{anchor}\)，新分支输出为 \(a_{residual}\)，最终加速度为：

\[
a=a_{anchor}+g(z,|v|^2)\tanh(s)a_{residual}。
\]

其中，控制模型参数冻结；门控函数只依赖原子类型和速度平方等旋转不变量，输出被限制在较小范围；全局尺度 \(s\) 从 0 开始，因此模型初始化时与控制模型严格相同。这样做不是为了把两个模型简单相加，而是让新分支从一个已知稳定的起点学习有限修正。

**5. 联合评估。** 我们不使用单一 RMSE 决定模型是否有效。内部评估同时记录 T1/T2/T3 坐标误差、预测步幅与真实步幅之比、梯度裁剪率、数值有限性、旋转/反射等变误差，以及必要的碰撞和局部几何代理指标。最新版没有公布四维指标的精确权重，因此初赛阶段只报告原始指标，不自行拼接“官方总分”。

### 3.2 预期方法路线

第一阶段完成数据、单位和基线复现；第二阶段通过小规模、可控的消融实验筛选时间结构和空间结构；第三阶段把通过门槛的多时间尺度监督迁移到三维等变模型；第四阶段训练锚定式残差，并联合约束坐标误差、轨迹幅度和残差能量；最后在完成蛋白质同源和配体 scaffold 审计后，再进行完整训练和正式评估。

对于 PVB、EPT、DPLM、ProTDyn 等预训练或动力学模型，我们目前主要借鉴其结构设计。只要无法获得明确的训练复合物 ID，或不能排除测试体系及其近同源样本，就不把相关权重放入正式候选。这样会牺牲一部分短期尝试速度，但可以避免预训练数据泄漏带来的虚高结果。

### 3.3 数据来源、依赖工具与运行流程

数据来自公开的 MISATO 数据集和 NeuralMD 提供的处理脚本、划分文件及官方检查点。主要环境为 Ubuntu 22.04、Python 3.10.20、PyTorch 2.6.0+cu124、CUDA 12.4 和 PyTorch Geometric 2.6.1；训练服务器配有 4 张 NVIDIA RTX A6000，根据空闲情况使用。

运行流程如下：

1. 下载数据并校验文件大小、MD5 和 HDF5 可读性；
2. 核对原始划分，执行多肽过滤和有限值检查；
3. 运行 NeuralMD published checkpoint，确认基线和三个预测场景；
4. 候选模型先通过单元测试、数值有限性和等变性测试；
5. 在 train-only 的开发划分上做配对实验，保存配置、随机种子和原始 JSON；
6. 只有同时通过坐标、动力学和稳定性门槛的候选才进入更大规模训练。

## 四、阶段性实验结果或可行性验证

### 4.1 阶段性实验或可行性验证

**完整数据链路。** 全量 MISATO 的文件哈希、16,972 个 HDF5 group、三份划分 ID 和去多肽后的数量均已核对。48 个分层抽样复合物通过 schema 和有限值检查。流式数据集已经能够从完整训练集读取样本，并在 GPU 上完成前向、反向和非零有限梯度计算。CUDA 预热后，该 smoke case 的单次前向/反向时间为 0.009288 秒。

**单位一致性。** 解析零加速度对照发现，时间缩放与初始速度定义不一致会让第一步位移只剩正确值的约 1%。把 `initial_velocity_scale` 改为 100 后，第二观测帧 RMSE 降至约 \(3.6\times10^{-8}\) 到 \(5.6\times10^{-8}\) Å，三个场景的步幅比恢复到 0.916-1.028。不过恒速度模型的 T3 RMSE 仍为 33.88 Å，这说明单位修正是必要条件，但不是长程预测的完整答案。

**多时间尺度代理实验。** 在 12 维轨迹不变量任务上，我们用 3 个随机种子比较一步训练 Transformer 和 `[5,10,20,40]` 多时间尺度闭环训练。一次冻结验证中，T3 RMSE 从 0.50540 降到 0.47716，相对改善 5.59%；宏平均 RMSE 从 0.40821 降到 0.39609，相对改善 2.97%。三个种子的 T3 变化方向一致。这个实验说明多尺度闭环值得迁移，但它不是三维原子轨迹的正式成绩。

**速度感知三维模型。** 速度感知 E(3) 模型在真实训练复合物上通过了 7 项正确性测试，旋转和反射误差分别为 \(3.81\times10^{-5}\) Å 和 \(3.05\times10^{-5}\) Å。在 36/12 的小规模开发划分上，它相对 position-only 模型将 T1/T2/T3 RMSE 分别降低 33.1%、45.9% 和 80.5%，但 T3 步幅比只有 0.1135，裁剪率达到 98.3%。因此我们没有把它当作有效提升，而是将其判为“坐标误差改善、动力学坍缩”。

**有界速度模型。** 在完整训练集重新抽取的 32/8 train-only 配对实验中，有界归一化速度模型把 T3 步幅比从 0.0763 提高到 0.6014，但 T3 RMSE 从 6.239 Å 恶化到 23.586 Å，T1/T2 同样恶化，裁剪率仍为 85.42%。这说明仅靠限制阻尼并不能兼顾运动幅度和轨迹方向。该方案已经停止，不再事后扫参。

**锚定式残差正确性验证。** 我们随后实现了 control-anchored gated E(3) residual。在真实复合物 `4K6V` 上，初始化输出与冻结控制模型的最大误差为 0；残差尺度梯度有限且非零；单步更新后残差非零但相对幅度只有 \(6.588\times10^{-8}\)；控制模型参数保持逐位不变；旋转和反射等变误差分别为 \(2.086\times10^{-7}\) 和 \(2.682\times10^{-7}\)。7 项门槛全部通过。

### 4.2 当前结果

现阶段最确定的结果不是“某个模型已经全面超过基线”，而是形成了一条可以继续推进的研究路线。

一方面，我们确认了多时间尺度闭环对长程外推有稳定的机制信号；另一方面，三维实验说明速度信息确实有用，但如果只优化坐标误差，模型很容易走向静止或强裁剪。锚定式残差正是针对这个失败提出的：它从稳定控制模型出发，只允许新分支逐步加入受限修正。目前它已经证明可实现、可训练、不会改动锚点，并满足 E(3) 等变性。

我们仍把已发表的 NeuralMD 作为主基线，因为锚定式残差现在通过的是正确性门槛，还没有完成完整效果门槛。接下来将使用新的 train-only 8/4 划分，比较冻结控制模型和锚定式残差，要求 T3 RMSE 改善、T3 步幅向真实值靠近、T1 不明显恶化、残差能量有界；任何一项失败都不会进入完整训练。

## 五、复现与开放计划

### 5.1 复现方式

项目代码和实验记录维护在：<https://github.com/ytq0198/Protein-Quanta>。

仓库中保存了固定配置、随机种子、数据审计脚本、模型实现、评估代码、原始 JSON 和逐项实验报告。NeuralMD 上游提交固定为 `a2ae030838c6ea0251eb6a29bfe99dc9d8ee1cfe`，MISATO 代码提交固定为 `7b06d532e2ed0719411fcc1b3ac39743db4ca10d`，官方检查点 SHA256 为 `364404a7ce61ec1180fa3800c0dcbddf377b672d22f915fc6b19d202710a4a5a`。截至冻结证据提交 `ae16cbb`，测试记录为 193 项通过，另有 33 个子测试通过。

复现时先按说明合法获取 MISATO 数据并核对 MD5，再生成过滤后的划分，运行数据 smoke test、published baseline 和候选模型门槛。大型数据文件和第三方权重不进入 Git 仓库，只记录来源和校验值。

### 5.2 开源计划

我们计划开放数据审计、场景评估、多时间尺度闭环、速度感知等变模块、锚定式残差、实验配置和结果报告。MISATO 原始数据、第三方检查点等无权重新分发的内容不会随仓库发布。项目级许可证将在完成依赖兼容性复核后确定。

### 5.3 依赖、数据来源与合规披露

核心开源依赖包括 PyTorch、PyTorch Geometric、h5py、MDAnalysis 和 NeuralMD/MISATO 的公开代码。当前训练和评估流程不依赖商业 API 或闭源模型。

外部预训练权重目前没有进入正式候选。PVB、EPT、DPLM、ProTDyn 等模型在许可证、训练 ID 或近同源排查没有闭环前，只作为文献和架构参考。正式评估前，我们还会完成蛋白质同源和配体 Bemis-Murcko scaffold 审计，并按比赛要求披露所有外部数据、权重来源和关键版本。
