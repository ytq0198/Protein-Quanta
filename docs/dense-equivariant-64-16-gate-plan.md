# 稠密等变模型 64/16 三 seed 效果 gate

## 目标

判断已经通过实现正确性和安全 preflight 的稠密径向场，加入冻结的 `[5,10,20,40]` 多时间跨度损失后，是否在完全 train-only 的 16-complex holdout 上产生可重复的 T3 收益，而不是仅保持物理安全。

## 公平性

每个 seed 的控制与候选从同一个 state dict 深拷贝，使用同一 64-development、同一 batch 顺序、同一局部窗口和同一多尺度窗口。控制仍计算同一多尺度前向以匹配计算预算，但系数为 0；候选系数为 0.25。训练 50 epoch，final checkpoint，不按 holdout 选 epoch。

场景严格为新版 `T1 10→10 / T2 80→20 / T3 20→80`。初始位置与速度只由观测区间最后两帧构造，不读未来 target。官方权重未公开，因此主汇总使用 T1/T2/T3 等权宏平均，并同时报告每个场景原始值。

## 通过条件

完整条件见 `configs/dense_equivariant_64_16_effect_gate.json`。核心包括宏平均改善、至少 2/3 seed 胜出、T1 回退不超过 2%、T3 RMSE 改善至少 3%、T3 误差斜率改善至少 5%，以及 RMSF/Rg/contact 至少两项改善。显式拓扑覆盖子集还需满足 bond MAE 回退不超过 5%、极端事件不增加超过 0.05 个百分点；所有 rollout 必须有限。

## 留出集封存与程序隔离

- `train_dense_equivariant_effect_seed.py` 只接收 64 个 development ID，不接受留出集参数；每个 seed 仅产生两份最终检查点和一份训练完成清单。
- `evaluate_dense_equivariant_effect_gate.py` 必须先找到三份完成清单和六份最终检查点，并逐一核对 SHA-256；在此之前程序不会读取 holdout ID、拓扑报告或 MISATO 轨迹。
- 三个 seed 的训练超参数和配对日程一经启动不得依据留出结果修改；统一评估只运行一次，并同时输出通过或失败的全部闸门。
- 留出集目标轨迹在六份检查点冻结前不打开。为建立 Phys 指标，留出样本 ID 及其首帧配体几何此前仅用于与 RCSB PDB 显式 `CONECT` 拓扑做原子顺序匹配；因此报告中称其为“目标轨迹封存”，而不夸称留出集身份完全未知。

## 中止试跑

2026-08-14 曾启动一个旧版 seed 42 脚本。发现该脚本在单个 seed 训练后会立即评估留出集后，控制组第 6 个 epoch 处被人工终止；它未完成控制组、未启动候选组、未生成检查点或评估报告，因而全部作废，不计入正式效应实验。正式运行从隔离后的脚本重新开始。

## 资源预算与停止条件

预估共有 `64 × 50 × 2 × 3 = 19,200` 个训练样本更新，每个更新包含局部与多尺度 ODE 前向。稠密模型峰值显存很低，但服务器数据 I/O 启动约 1–2 分钟。三 seed 可各占一张空闲 GPU；启动前重新检查实际占用，不抢占他人进程。任一 seed 出现非有限 loss/gradient、OOM、蛋白移动或裁剪率超过 50%即停止该 seed 并保留失败结果。

预计三 seed 训练和完整 16-complex 场景评估需要数小时。运行期间每个 checkpoint 保存配置、commit、seed 与 SHA256；坐标轨迹和权重只留服务器，不进 Git。

## 防止把数值噪声写成创新

此前 5-epoch preflight 中候选/控制 RMSE 只差约 `9e-8`。因此正式 gate 除百分比外，还报告 checkpoint 相对初始参数的 L2 位移、候选与控制的参数 L2 差、逐 seed 配对差和标准差。相对差低于 `1e-6` 时标记为数值可忽略，即使方向为正也不称为改善。
